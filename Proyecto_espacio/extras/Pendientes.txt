Eventos 

Crear un nuevo evento:

Incribir un cliente a un evento:
    Primero y principal tenemos q tener una select que diga "cliente cargado" o "nuevo cliente" 
        si es cliente cargado seleccionamos de la lista que le pasamos a la vista (luego sera de la base de datos de clientes)
        si es nuevo cliente (se habilitan los datos para cargar un cliente especifico para el evento)
detelle eventos:
    vamos a mostrar de un lado del contenedor el detalle de los campos, al lado la foto que cargamos para el evento
    debajo el listado de clientes que agregamos
        en este listado vamos a tener los clientes con dos botones
            confirmar: este boton se muestra si no confirmamos el pago (este boton se muestra si el costo no es 0 "es gratis")
            eliminar: eliminar el cliente de la lista, el cupo se suma a los cupos restantes
